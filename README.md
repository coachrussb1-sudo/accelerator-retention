# ACCELERATOR

Retention breakdown for Instagram reels. Walk every section — hook, setup, body, payoff, CTA — and get a verdict plus one fix.

Live: https://coachrussb1-sudo.github.io/accelerator-retention/

by Coach Russ / TRIUMFIT

## Run locally

```bash
npm install
npm test
npm run dev
```

Open http://127.0.0.1:4391/

## Use it

1. Video length in seconds.
2. Retention % at 0, 1s, 3s, then 10% steps (from IG reel insights). Drag the dots.
3. Optional skip rate, average watch time, and a local video file for thumbnails.
4. See the breakdown. Email is optional.

Load **Example data** to walk the bundled how-to clip. Those numbers are labeled example data, not real analytics.

Rules of thumb for coaching — not Meta benchmarks.
